# Blockers

This folder contains standalone descriptions of obstacles encountered while
trying to prove

$$
D_K(n)=\omega(\log K)
$$


for every starting value of one coprime residue-affine Collatz-like map.  The
current blocker analyses mostly concern the pure-division subfamily.  A
blocker is not a proof that the target is impossible; it identifies the
precise point at which a proof architecture currently needs a new theorem.

- [`moving_endpoint_core_obstruction.md`](moving_endpoint_core_obstruction.md)
  explains the obstruction left by the prime-power macro-chain approach.
