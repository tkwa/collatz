# Prime-power macro chains

This note extends the `4/3` odd-core calculation to every one-expanding-residue
map whose expansion multiplier is a prime power.  The result is proved and is
independent of the particular diagnostic map.  It removes arbitrary short
intervening blocks, but it still leaves unrestricted prime-to-`pB` endpoint
cores and therefore does not prove the superlogarithmic target.

## Setup

Use the centered one-expanding-residue normal form from
[`research_state.md`](research_state.md), and suppose

```math
a=p^g
```

for a prime `p\nmid B` and `g\ge1`.  Index consecutive division blocks so that

```math
B^{r_i}u_i=a^{L_{i-1}}u_{i-1}+d_i,
\qquad r_i=L_i+1,
```

where `d_i=-b_{r(i)}` belongs to a fixed finite set of nonzero signed
integers.  Write

```math
t_i=v_p(d_i),
\qquad
\varepsilon_i=d_i/p^{t_i},
```

so every `\varepsilon_i` is a signed `p`-adic unit.  Put

```math
t_{\max}=\max_i t_i.
```

## Endpoint reset

If

```math
gL_{i-1}>t_i,
```

then the two terms on the right of the block recurrence have different
`p`-adic valuations, and hence

```math
v_p(u_i)=t_i.
```

In particular, call a run index `j` **marked** when

```math
gL_j>t_{\max}.
```

Then the unit following that run has the controlled factorization

```math
u_{j+1}=p^{t_{j+1}}w_{j+1},
\qquad p\nmid w_{j+1},
\qquad B\nmid w_{j+1}.
```

The condition `B\nmid w_{j+1}` follows from the definition of the endpoint
unit; `p\nmid w_{j+1}` follows from the exact reset.

## Macro elimination between marked runs

Let `j<k` be marked indices.  Eliminating the intermediate units from the
block recurrences with indices `j+2,\ldots,k+1` gives

```math
B^{R_{j,k}}u_{k+1}
=a^{A_{j,k}}u_{j+1}
+\sum_{i=j+2}^{k+1}
d_i
B^{\sum_{h=j+2}^{i-1}r_h}
a^{\sum_{h=i}^{k}L_h},
```

where

```math
R_{j,k}=\sum_{i=j+2}^{k+1}r_i,
\qquad
A_{j,k}=\sum_{h=j+1}^{k}L_h.
```

The last correction summand has exact `p`-adic valuation `t_{k+1}`.  Every
earlier summand contains the factor `a^{L_k}=p^{gL_k}` and therefore has
strictly larger `p`-adic valuation, because `k` is marked.  Division by
`p^{t_{k+1}}` yields

```math
\boxed{
B^{R_{j,k}}w_{k+1}
=p^{S_{j,k}}w_{j+1}+C_{j,k},
}
```

with

```math
S_{j,k}=gA_{j,k}+t_{j+1}-t_{k+1}
```

and

```math
C_{j,k}
=\sum_{i=j+2}^{k+1}
\varepsilon_i
p^{g\sum_{h=i}^{k}L_h+t_i-t_{k+1}}
B^{\sum_{h=j+2}^{i-1}r_h}.
```

Every exponent of `p` in the last display is nonnegative.  The final summand
has exponent zero and is a `p`-adic unit, so

```math
v_p(C_{j,k})=0.
```

If `k-j\le R`, the correction contains at most `R` explicit monomials from a
fixed multiplicative group generated by `p`, the prime divisors of `B`, and
the prime divisors of the finite coefficient alphabet
`\{\varepsilon_i\}`.

## Consequence of hypothetical failure

The piecewise-syndetic theorem in
[`failure_structure.md`](failure_structure.md) applies to every sufficiently
large proportional gap, hence to marked runs.  If the superlogarithmic target
failed, one fixed spacing bound `R` would support arbitrarily long chains of
marked indices.  Along such a chain, the controlled cores `w` are linked by
the boxed macro equations, with at most `R` correction monomials per link.

Thus short intervening runs and their uncontrolled `p`-adic cancellations are
not the final obstruction.  The remaining missing statement is a global
theorem preventing an arbitrarily long chain of these equations when all
prime-to-`pB` cores come from the same fixed starting integer.  Local Chinese
remainder arguments cannot do this, because every finite itinerary is
realizable.

## Specialization

For

```math
(B,p,g)=(3,2,2),
```

with correction alphabet `{2,4}`, the boxed identity is exactly the macro
odd-core link in [`odd_core_chain.md`](odd_core_chain.md).
